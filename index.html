# A tiny markdown blog engine Everything below this line is plain markdown in a single `data-format="markdown"` element — the `#` heading renders as a `<h2>` so it nests under the page title. Mix in *emphasis*, **strong text**, ~~strikethrough~~, and `inline code` freely.
## Text and lists Unordered lists, with **bold**, *italics*, and [links](https://example.com): * first item * second item, with a [nested link](https://marked.js.org) Ordered lists work too: 1. write some markdown 2. `npm run build` 3. `npm run deploy` > Blockquotes are great for pull quotes, credits, or a word of warning. ## Code Fenced blocks are syntax-highlighted, and the code theme is inverted against the page theme — toggle the switch in the footer: ```python def hello(name: str) -> str: """Greet someone, politely.""" return f"Hello, {name}!" ``` ```bash npm run build # bundles JS + CSS into dist/ npm run deploy # publishes dist/ to GitHub Pages ``` ## Tables and tasks | Syntax | Result | | ---------------- | ----------------------- | | `**bold**` | **bold** | | `*italic*` | *italic* | | `` `code` `` | `code` | | `> quote` | > quote | - [x] render markdown in place - [x] syntax-highlighted code blocks - [ ] your first post ---
